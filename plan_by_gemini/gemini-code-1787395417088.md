# Engineering Specification & Implementation Plan
# Project: DalalStreet-Agent (Indian Financial Multi-Agent Research & Annual Report Auditor)

---

## 1. Project Overview & Target Architecture

### 1.1 Summary
**DalalStreet-Agent** is an autonomous multi-agent financial auditing engine tailored for the Indian capital markets (NSE & BSE). The system ingests and indexes complex corporate Annual Reports (PDFs), queries real-time financial market fundamentals using the **Model Context Protocol (MCP)**, coordinates specialized sub-agents via **LangGraph**, and applies a self-correcting **Critic/Auditor loop** to flag discrepancies between qualitative management claims and actual numbers.

### 1.2 Core Architectural Principles
* **Stateful Graph Orchestration:** LangGraph state machine handles explicit branching, parallel data retrieval, and cycle-based self-healing.
* **Open Standard Tooling (MCP):** Real-time equity data tools are wrapped as an independent Model Context Protocol server using FastMCP.
* **Deterministic Verification (Critic Loop):** Evaluates extracted qualitative statements against quantitative metrics (P/E, operating margins, debt-to-equity) to eliminate hallucinations.
* **100% Zero Cost Pipeline:** Utilizes Google Gemini 1.5 Flash (Free Tier via Google AI Studio), local `sentence-transformers` CPU embeddings, and embedded ChromaDB.
